# Where Is It

A World of Warcraft: Forever addon (Interface 16001; also loads on Classic Era 1.15)
that adds a short, encyclopedia-style note to item tooltips about where an item is
usually found. It is deliberately vague: kinds of creatures, merchants or crafts and
the one or two regions where the item is most plentiful, never coordinates, NPC
names or drop percentages.

Examples of what the tooltip shows:

| Item | Alliance | Horde |
| --- | --- | --- |
| Simple Wood | Sold by general goods merchants in most settlements. | same |
| Small Egg | Commonly carried by carrion birds and owls of levels 5-17, most plentifully in Westfall and Teldrassil. | Commonly carried by carrion birds of Mulgore. |
| Pitted Defias Shortsword | A rare find on Defias brigands of Elwynn Forest. | A rare find on Defias brigands in Alliance territory. |
| Perdition's Blade | Won from the great foes within Molten Core. | same |
| Thunderfury | Forged at the end of a legendary quest chain. | same |

Regions are filtered by faction: Westfall is never suggested to a Horde player and
Durotar never to an Alliance player. When the only sources sit in the other faction's
lands the hint says so instead ("in Horde territory").

## Installing

Copy this folder into `Interface\AddOns\WhereIsIt`. The encyclopedia's accounts live in a
companion addon kept inside it, `WhereIsIt_Lore/`; the game only loads addons from the top
of `AddOns`, so either copy that folder out beside `WhereIsIt` or make a junction to it:

```bash
cmd /c mklink /J "Interface\AddOns\WhereIsIt_Lore" "Interface\AddOns\WhereIsIt\WhereIsIt_Lore"
```

Both addons must be enabled in the addon list. The companion is load-on-demand and only
loads when the book is opened. Licensed under the MIT License (see `LICENSE`).

## The encyclopedia

Alt-click any item whose tooltip is showing (bags, bank, character sheet, merchant,
profession window reagents and results, auction house, quest rewards, chat links), click
the minimap button, or type `/wii` to open a leather-bound book:

* **Left page, the entry:** the faction's crest and the *Encyclopaedia Azerothica*
  banner, then the item's icon in a gilt frame, its name in its quality colour, kind
  and required level, the item's own flavour text, a *Provenance* list with every
  ranked hint line (the tooltip only shows the first two), and *Of use to* (which
  crafters want it as a reagent, which regions' questgivers ask for it, what a recipe
  teaches), opening with an illuminated initial in the faction's colour.
* **Right page, the atlas:** *Where to look*, an ink-wash chart of the region where
  the item is most plentiful for your faction, drawn from the client's own map art
  and glued in with a toasted rim, with a caption. Below it the *Index*: type to search
  all 13,000 names, or see recently consulted entries.
* **The account:** below the entry, or overleaf when it runs long, one or two paragraphs
  in the voice of an encyclopaedist: what the thing is, whose work it is, and where and
  from whom it is had, grounded in the land's history and the habits of its peoples. Arrows
  beside the page number, the mouse wheel over the left page, or the controller turn the
  leaf. The accounts live in the companion addon `WhereIsIt_Lore`, which loads the first time
  the book is opened, so the tooltip never pays for them.
* **The faction ribbon:** a bookmark hanging out from beneath the left page carries
  the crest of the other faction. Click it to read the entry as recorded for them; the
  note at the foot of the page says which faction's record you are reading. The gold *Settings* ribbon at the top opens the options panel.

The parchment, leather, ribbons, gilt fittings, vines, banners and illuminated
initials are all generated by `tools/make_media.py`, so nothing is borrowed from
another addon. The faction crests are the client's own. To paint your own art, see
`ART_ASSETS.md` for every file's size, crop, tinting and placement.

### Controller

With Forever's gamepad support on, the book can be driven from the pad while it is open
(a legend with your controller's own button glyphs hangs beneath the book's bottom-right corner):

| Input | Action |
| --- | --- |
| D-pad or left stick | move the highlight; up/down past the list turns the results page |
| Bottom face button (A / cross) | open the highlighted entry |
| Right face button (B / circle) | close the book |
| Left face button (X / square) | flip the faction ribbon: show the entry for the other faction |
| Top face button (Y / triangle) | clear the search and show recent entries |
| LB / RB | older / newer consulted entry |
| LT / RT | previous / next page of search results |

Only buttons the book uses are consumed; everything else still reaches the game. The book
closes itself when combat starts, because input capture cannot change during combat. To
open it from the pad, bind a button to *Where Is It > Open or close the encyclopedia*
under Key Bindings, or set the game's Alt emulation on a pad button and Alt-click an item.
`/wii gamepad` turns controller navigation off and on.

## Options

`/wii` (or `/whereisit`) opens the book; `/wii config` opens the options panel.
Sub-commands:

| Command | Effect |
| --- | --- |
| `/wii search <name or itemID>` | open the book on a search or an item |
| `/wii toggle` | turn the tooltip line on or off |
| `/wii lines 1-3` | how many hint lines to show on tooltips (default 2, ranked most useful first) |
| `/wii faction auto/alliance/horde/both` | which faction's regions to show |
| `/wii unknown` | also say when an item has no record |
| `/wii althint` | show or hide the faint "Alt-click to open the encyclopedia" tooltip line |
| `/wii altclick` | enable or disable Alt-click opening the book |
| `/wii minimap` | show or hide the minimap button (drag it to move it) |
| `/wii gamepad` | enable or disable controller navigation of the book |
| `/wii debug` | print which hooks are live, what the last click saw, and the controller state |
| `/wii find <itemID>` | print the hint for an item ID to chat |

## How the accounts are written

`tools/build_lore.py` composes the accounts from the same sources as the hints plus a
hand-written knowledge base: `tools/lore_world.py` (every zone and dungeon of the old
world, the peoples and beasts that live there), `tools/lore_things.py` (trade goods,
herbs, ores, cloths, cultures whose names appear on gear, kinds of weapon and armour,
merchants and the crafts) and `tools/lore_bespoke.py` (full entries for notable items,
checked against the database by name). Passages shared between entries are stored once
and expanded when a page is rendered. Regenerate with:

```bash
python -I tools/build_lore.py --mangos path/to/mangos.sqlite --pfquest path/to/pfQuest/db --out WhereIsIt_Lore
```

## How the hints are built

`tools/build_data.py` generates `WhereIsIt_Data.lua` from two open-source datasets:

* the vmangos world database (<https://github.com/vmangos/core>, `db_latest` SQLite
  snapshot): loot tables (with reference loot resolved), vendors, skinning,
  pickpocketing, fishing, containers, crafting spells, trainers, quest rewards,
  disenchanting, creature/object templates and zone names;
* pfQuest spawn data (<https://github.com/shagu/pfQuest>, MIT): per-zone spawn points
  for creatures and objects in the open world, which gives "where is the densest
  population" and which faction an NPC serves.

For creature drops every zone is scored as `spawn count x drop chance`; the top one or
two zones the player's faction can visit are named, and the creature description is
whatever kind covers most of that score (pet family for beasts, name keywords for
humanoids, undead, demons and so on). Wording tiers follow the drop chance
("Commonly carried by", "Often found on", "Sometimes found on", "A rare find on",
"A very rare find on"). Dungeon drops become "the Defias of the Deadmines" style lines,
boss-only drops "Guarded by a master of ..." or "Won from the great foes within ...".

Regenerate after downloading the two datasets:

```bash
python -I tools/build_data.py --mangos path/to/mangos.sqlite --pfquest path/to/pfQuest/db --out WhereIsIt_Data.lua
```

`tools/check_lua.py <addon dir>` compiles the Lua files (and the lore companion, if built) with a real Lua 5.1 (needs
`pip install lupa`) and exercises the tooltip hook, the book and the search with stubbed
WoW APIs. `tools/make_media.py` redraws the textures (needs `pip install pillow`).

## Limitations

* The data describes vanilla Azeroth (1.12). Forever's new zones, dungeons and items,
  and anything it revamped, are not covered; those tooltips simply get no line.
* Spawn density and drop chances come from a private-server reconstruction, so a hint
  can occasionally point at a zone that is not the best one in the live game.
* Summoned bosses have no spawn point in either dataset; the most common ones are
  mapped by hand in `BOSS_ZONE_OVERRIDE`, others fall back to a zone-less line.
